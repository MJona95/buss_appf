# Buss App

Buss App is a modern public and private transportation utility application built using Flutter. Recreated from the custom Zenith Transit & BusGo design specs, it features:
- **Explore Trips (Inicio):** Interactive search and featured trip packages.
- **Stations Map (Mapa):** Nearby station lists with live countdown trackers and visual location pins.
- **Public Transport Directory (Autobuses):** View capacity, hours, and direct WhatsApp contact for active transit units.
- **Private Transport (Transporte Privado):** Direct booking forms for executive travel with offline SQLite logging and Supabase sync.

This project is built using Clean Architecture with feature-first organization, local storage caching via `sqflite`, and cloud connectivity using `supabase_flutter`.
